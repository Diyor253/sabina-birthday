# Сайт-поздравление для Сабины

## Как открыть
1. Распакуй архив.
2. Открой папку `sabina_birthday_site` в VS Code.
3. Открой `index.html` в браузере (или используй расширение Live Server).

## Файлы
- `index.html` — структура сайта и текст поздравления.
- `style.css` — розовый дизайн, адаптация под телефон и анимации.
- `script.js` — подарок, письмо, секретное сообщение, сердечки и управление музыкой.
- `wanna-be-yours.mp3` — добавь сюда свой легально полученный аудиофайл песни «I Wanna Be Yours».

## Как изменить
- Текст письма и имя: редактируй `index.html`.
- Секретное сообщение: найди в `index.html` текст `Ты делаешь мой мир прекраснее и спокойнее`.
- Цвета и внешний вид: редактируй переменные в начале `style.css`.
- Музыка: положи аудиофайл песни в папку проекта и назови его точно `wanna-be-yours.mp3`. Сам аудиофайл в архив не включён.

Для включения звука пользователь должен нажать кнопку — это обычное ограничение браузеров. Используй аудиофайл, который у тебя есть право использовать.
